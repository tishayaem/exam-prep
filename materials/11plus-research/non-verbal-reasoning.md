# GL Non-Verbal & Spatial Reasoning — taxonomy with worked examples

NVR is visual, so every worked example below is **described in words precisely enough to solve from the text alone** (shapes, shading, count, position, rotation). Examples marked **[OFFICIAL]** are reconstructed from GL's real free familiarisation booklet (Analogies + Codes sections); the rest are constructed here and checked so the stated answer follows necessarily from the description.

## Critical framing
GL does **not** publish a named list of NVR types. The "12 NVR + 7 spatial" taxonomy below is a **tutoring convention** (examhappy, visuteach, Atom) reverse-engineered from real papers. GL's actual familiarisation booklet bundles everything into a few **answer-format families**: its NVR paper has just two section formats — **Analogies** ("make a pair", 20 Qs) and **Codes** (15 Qs). Treat the 12/7 list as a teaching scaffold.

- **Paper format (corroborated):** ~**80 questions in 4 sections of 20, ~60 min, each section separately timed.**
- **Spatial Reasoning is a *separate* paper** used only in a few areas (Kent, Lincolnshire, Buckinghamshire), introduced ~2015. **Most GL regions test NVR without spatial — confirm before drilling cube-nets/paper-folding.**
- **The universal "rules examiners vary":** rotation, reflection/mirroring, number of sides, shading (black/white/striped/dotted/grey), size, count (elements/dots/lines), position, line style (solid/dashed), and addition/subtraction of elements. Every type is these rules in a different answer format.

## CORE NVR TYPES

### 1. Series / Sequences
Pick the figure that continues a row that changes by a fixed rule.
- Squares with 1, 2, 3 black dots → next has **4 dots**  · *count +1 each step.*
- Arrow rotating 90° clockwise (up, right, down, ?) → **left**  · *continue the 90° CW turn.*
- Circle shaded ¼, ½, ¾, ? → **fully black**  · *shaded quarter +1 each step.*

### 2. Analogies (A:B :: C:?) **[OFFICIAL — GL Section 1]**
GL wording: *"decide how the second is related to the first… find which shape goes with the third to make a pair like the two on the left."*
- **[OFFICIAL]** solid shield → solid square; so **dashed shield → dashed square, same size**  · *shape changes shield→square; size & line-style preserved.*
- **[OFFICIAL]** black shape with white insert → same shape with shading reversed; so a black hexagon-with-white-keyhole → **white hexagon with black keyhole**  · *rule = reverse all shading.*
- **[OFFICIAL]** blob → same blob rotated 180°; apply 180° rotation to the test shape, same size  · *reject reflected/resized/other-angle options.*

### 3. Matrices (find the missing grid cell)
Work out the rule across rows and/or down columns; fill the blank.
- 2×2: white→black (L→R), small→large (top→bottom); missing cell = **large black**.
- 3×3, each row has dots 1/2/3; row-3 gap = **3 dots**  · *each row holds one of each count.*
- 3×3, arrow rotates 90° CW along each row; row-3 (up, right, ?) = **down**.

### 4. Odd One Out / Most Unlike
Pick the one figure that breaks a rule the other four share.
- Four have a dot **outside** the shape, one **inside** → **the inside-dot one**.
- Four arrows have an **odd** number of tail lines, one has **2** → **the 2-line arrow**.
- Four obey "sides = internal dots" (triangle+3, square+4…), one is **pentagon+3 dots** → **odd one**.

### 5. Codes (shapes → letter pairs) **[OFFICIAL — GL Section 2]**
Each letter-position encodes one feature. Deduce the meanings, then code the test shape. *A new code is used every question.*
- **[OFFICIAL]** white circle=XS, striped square=YT, white square=YS → striped circle = **XT**  · *top letter = shape (circle X / square Y); bottom = shading (white S / striped T).*
- **[OFFICIAL]** circle-0dots=MG, triangle-1dot=NH, circle-2dots=MI → triangle-0dots = **NG**  · *top = shape; bottom = dot count (0 G / 1 H / 2 I).*
- **[OFFICIAL]** six-sided=R, four-sided=S; striped=F, plain=G, black=H → plain six-sided = **RG**.

### 6. Most Similar / Belongs-with-group
Pick the figure that **also** obeys the hidden rule the given figures share (inverse of odd-one-out).
- Givens: triangle+3 dots, square+4 dots → **pentagon+5 dots**  · *rule: dots = sides.*
- Givens both have exactly one line of symmetry → pick the **one-mirror-line** option.

### 7. Reflection (mirror image)
Pick the mirror image across the stated line.
- "F" with arms pointing right, vertical mirror → **"F" with arms pointing left**  · *vertical mirror swaps left/right.*
- **Key trap:** reflection ≠ rotation. Track a chiral feature (a notch/corner dot) — a reflected figure can't be obtained by spinning the original in the page plane.

### 8. Rotation
Pick the figure **turned** (not flipped) by the stated angle.
- "L" rotated 90° CW → **L on its back, foot pointing up-right**.
- Arrow at 12 o'clock rotated 180° → **points to 6 o'clock**  · *opposite direction, but NOT a mirror image.*

### 9. Symmetry
Identify/complete a figure by its symmetry.
- Which has **exactly 2 lines of symmetry**? square(4), rectangle(2), equilateral triangle(3)… → **rectangle**.
- A parallelogram has **rotational symmetry order 2 but no mirror line** — distinguish rotational from reflective symmetry.

## SPATIAL SUBSET (separate GL Spatial paper — Kent / Lincs / Bucks only)

> Sources disagree on the count (examhappy 7, visuteach effectively 9). Block-counting and 2D-views-of-3D are the genuinely 3D items; the rest are 2D-on-paper.

### 10. Nets / Cubes (fold a 2D net into a cube)
- Cross net, centre=star, arms=circle/square/triangle/heart, top-of-column=moon → opposite pairs: **star–moon, circle–square, triangle–heart**  · *faces two squares apart along a line fold to opposite sides.*
- A cube showing **star and moon on two adjacent faces is impossible** — they're an opposite pair.
- Even with the right faces adjacent, reject a cube where a face's pattern is **rotated/mirrored** to the wrong orientation.

### 11. 3D Rotation / Views ("matching shape")
Pick the option that is the **same** object merely **rotated** (not mirrored).
- L-shaped 3-cube tromino with a red corner cube → rotated copy keeps the **red cube at the corner**; a mirror version is a *different* object.
- Asymmetric flat "boot": four options are flipped (mirror), one is rotated → pick the **rotated** one.

### 12. Hidden / Embedded Shapes
Find which complex figure contains the target **at the same size and orientation**.
- Plain right-angled triangle buried (unrotated, unresized) among overlapping lines → that figure  · *reject options needing the target rotated/resized.*

### 13. Combining Shapes
Join shapes along **labelled matching edges** (grey = subtract/cut out).
- Square + triangle joined on the square's right edge → **house-pentagon**.
- Rectangle with a grey circle subtracted from the centre → **rectangle with a circular hole**.

### 14. Cube / Block Counting
Count all cubes **including hidden support cubes**.
- Staircase columns 1, 2, 3 tall (one deep) → **6**  · *sum the column heights.*
- Solid 3×3 front face, 2 deep → **18**  · *3×3×2; the hidden back layer must exist.*

### 15. Paper Folding & Hole-Punching
Each fold **doubles** the holes; punched holes **reflect across every fold line**.
- One vertical fold, one punch → **2 holes**, mirror-symmetric about the centre line.
- Two folds (½ then ½), one punch → **4 holes**, one per quadrant  · *2 folds = 2² = 4; trap: folded-under holes come out as **mirror images**, not same-place copies.*

*(Jigsaw — find the missing piece, rotating to fit — and figure-recognition are extra spatial items some publishers list, which is why counts vary.)*

## Caveats
1. No official GL type list — "12 NVR / 7 spatial" is a tutoring convention.
2. Reflection/Rotation/Symmetry are usually the *rule inside* an analogy/series/matrix, not standalone sections. The **#1 trap is a reflection distractor against a rotation answer** — drill the chirality check.
3. Spatial Reasoning is **not used in most GL regions** — confirm before building cube-net/paper-folding practice.
4. Only **[OFFICIAL]** examples are quoted from GL material; the rest are constructed and self-checked. Use downloadable GL/CGP papers for authentic volume.
